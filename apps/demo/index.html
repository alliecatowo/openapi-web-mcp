Swapping the document re-derives the agent's whole tool set. Nothing about the plugin changes.

Three lines in your existing Swagger UI

import SwaggerUIWebMCP from "swagger-ui-webmcp";

SwaggerUI({
  dom_id: "#swagger-ui",
  url: "/openapi.yaml",
  plugins: [SwaggerUIWebMCP],          // ← the whole integration
  webMcp: { exposure: "write" }
});

No AI SDK. No MCP server to install. No bearer token leaves the page. The agent inherits whichever server you picked in the dropdown below and whatever session you are already signed into.

Try the SEE-vs-CALL demo

Three operations declare x-webmcp.requiresAuth and stay visible but uncallable until you authorize in Swagger UI below (the Authorize button). An agent calling one early gets a structured AUTH_REQUIRED error; after you authorize, the same call succeeds.

  • bearerAuth (HTTP bearer, gates the usage report): waypoint-demo-bearer
  • waypointKey (header X-Waypoint-Key, gates export creation): waypoint-demo-key
  • waypointQueryKey (query key, gates export status): waypoint-demo-query-key
